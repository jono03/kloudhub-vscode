# KloudHub

KloudHub에서 만든 내 환경과 서버를 VS Code 사이드바에서 보고, 클릭 한 번으로 서버에 원격 접속합니다.

- 프로젝트 → 환경 → 서버 순서로 내 자원을 보여 줍니다.
- 서버를 누르면 **Remote - SSH** 원격 창이 열립니다. 쿠버네티스 워커처럼 공인 IP가 없는 서버는 같은 환경의 공인 IP 서버를 거쳐 자동으로 접속합니다.
- 환경 시작·정지, kubeconfig 받기, 웹에서 열기도 사이드바에서 할 수 있습니다.

## 준비

1. **Remote - SSH** 확장(`ms-vscode-remote.remote-ssh`)을 설치합니다.
2. 내 PC에 SSH 키가 있어야 합니다. 없으면 터미널에서 만드세요.
   ```bash
   ssh-keygen -t ed25519
   ```
3. 이 PC에서 KloudHub 웹 주소와 서버 IP 대역에 닿아야 합니다. 학내망이나 VPN 안에서만 열리는 곳이라면 그 망에 먼저 연결하세요.

## 로그인

1. KloudHub 웹에 로그인한 뒤 **설정 → API 토큰**에서 토큰을 발급합니다. 발급 화면에서 한 번만 보여 주니 바로 복사해 두세요.
2. VS Code 왼쪽 막대의 **KloudHub** 아이콘을 누르고 **로그인**을 누릅니다.
3. 화면 위쪽 입력칸에 차례로 넣습니다.
   - 주소: KloudHub 웹 주소 (예: `https://kloudhub.example.ac.kr`)
   - 토큰: 복사한 `kh_…` 값

명령 팔레트(Cmd/Ctrl+Shift+P)에서 **KloudHub: 로그인**을 실행해도 됩니다.

토큰은 OS 키체인에만 저장되고, 설정 파일에는 웹 주소만 남습니다.

## 사이드바 보는 법

아래는 예시입니다. 실제로는 로그인한 사람의 프로젝트와 환경이 나옵니다.

```
▾ my-project
  ▸ my-vm           개발 VM
  ▾ my-k8s          쿠버네티스
      cp0           203.0.113.10
      worker0       cp0 경유
      worker1       cp0 경유
  ▾ old-gitlab      GitLab
      🔒 gitlab0     키 없음
  ▸ test-vm         개발 VM · 정지됨
  ▾ 독립 인스턴스    1
      scratch       198.51.100.20
▸ other-project     환경 없음
```

- **보이는 범위**: 내가 만든 환경과, 환경에 속하지 않은 내 인스턴스(독립 인스턴스)만 나옵니다. 같은 프로젝트의 다른 사람 환경은 나오지 않습니다.
- **서버 아이콘 색**: 초록은 실행 중, 회색은 정지됨, 빨강은 오류입니다.
- **서버 오른쪽 글자**는 접속할 곳입니다.

  | 표시 | 뜻 |
  |---|---|
  | `203.0.113.10` | 이 서버의 공인 IP로 바로 접속 |
  | `cp0 경유` | 같은 환경의 공인 IP 서버(cp0)를 거쳐 접속 |
  | `접속 불가` | 이 서버에도, 같은 환경에도 공인 IP가 없음 |
  | 🔒 `키 없음` | 서버에 내 SSH 키가 없고 비밀번호 로그인도 꺼져 있음 |

- 역할, 사설 IP, 로그인 계정 같은 자세한 정보는 서버에 마우스를 올리면 나옵니다.

## 접속하기

서버 줄의 **접속** 버튼을 누르면 새 VS Code 창이 열립니다. 우클릭하면 다른 방법도 고를 수 있습니다.

| 메뉴 | 하는 일 |
|---|---|
| 새 창에서 접속 | 새 원격 창을 엽니다 |
| 현재 창에서 접속 | 지금 창을 원격 창으로 바꿉니다 |
| SSH 터미널 열기 | VS Code 터미널에서 ssh로 접속합니다. 오래된 OS처럼 원격 창이 안 열리는 서버에 씁니다 |
| SSH 명령 복사 | `ssh kloudhub--…` 명령을 복사합니다. 다른 터미널에서 붙여 넣어 쓸 수 있습니다 |
| SSH 사용자 변경 | 로그인 계정을 직접 정합니다 |

- **로그인 계정**은 서버 이미지에서 알아냅니다(Ubuntu는 `ubuntu`, Rocky는 `rocky` 등). 모를 때만 처음에 물어봅니다.
- **정지된 서버**에 접속하면 먼저 시작할지 묻습니다. 시작이 끝나면 이어서 접속합니다. 환경에 속한 서버는 환경 전체를 시작합니다.
- 접속 정보는 `~/.ssh/config`의 `KLOUDHUB-VSCODE` 블록에 기록됩니다. 그 블록 밖의 내용은 건드리지 않습니다. 제목줄 `···` → **SSH config 열기**로 볼 수 있습니다.

## SSH 키

서버에는 **서버를 만들 때** KloudHub에 등록돼 있던 내 공개키가 들어갑니다. 나중에 등록한 키는 이미 있는 서버에 들어가지 않습니다.

- **키 등록**: 제목줄 `···` → **SSH 공개키 등록**에서 `~/.ssh/*.pub` 중 하나를 고르면 KloudHub에 등록됩니다. 그 뒤에 만드는 환경과 인스턴스에 들어갑니다.
- **🔒 키 없음이 뜨는 경우**: 키를 등록하기 전에 만든 서버이거나, 다른 PC의 키로 만든 서버입니다. 그 키를 이 PC에 두거나, 설정 `kloudhub.ssh.identityFile`에 그 개인키 경로를 지정하세요. 접속을 누르면 경고가 먼저 뜨고, **그래도 접속**을 고를 수 있습니다.
- 서버를 만들 때 SSH 비밀번호 로그인을 켰다면 키가 없어도 비밀번호로 접속할 수 있습니다.

## 환경 메뉴

환경 줄을 우클릭하면 나옵니다.

| 메뉴 | 하는 일 |
|---|---|
| 환경 시작 / 환경 정지 | 환경의 서버를 모두 시작하거나 정지합니다. 끝날 때까지 진행 상황을 보여 줍니다 |
| kubeconfig 받기 | 쿠버네티스 환경의 내 kubeconfig(인증서 90일 유효)를 저장합니다. 저장 뒤 `export KUBECONFIG=…` 명령을 복사할 수 있습니다 |
| 웹에서 열기 | 브라우저에서 그 환경 화면을 엽니다 |

독립 인스턴스는 서버 줄에서 바로 시작·정지합니다.

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 로그인할 때 연결 오류 | 브라우저에서 웹 주소가 열리는지 확인합니다. 자체서명 인증서를 쓰는 곳이면 설정 `kloudhub.allowSelfSignedCertificate`를 켭니다 |
| "토큰이 만료됐거나 올바르지 않다" | 웹에서 새 토큰을 발급해 다시 로그인합니다 |
| `Permission denied (publickey)` | 서버에 이 PC의 키가 없습니다. 위의 **SSH 키**를 보세요 |
| 접속 시간 초과 | 이 PC에서 서버 IP 대역에 닿지 않습니다. 학내망이나 VPN에 연결합니다 |
| `접속 불가` 표시 | 웹의 환경 화면에서 공인 IP를 붙이거나, VPN으로 내부망에 닿는다면 설정 `kloudhub.ssh.allowPrivateAddress`를 켭니다 |
| 원격 창이 열리지 않음 | 오래된 OS(Ubuntu 18.04, CentOS 7 등)는 VS Code 원격 창을 지원하지 않습니다. **SSH 터미널 열기**를 씁니다 |

요청 기록은 **보기 → 출력**에서 `KloudHub`를 고르면 볼 수 있습니다.

## 설정

| 설정 | 기본값 | 설명 |
|---|---|---|
| `kloudhub.endpoint` | (빈 값) | KloudHub 웹 주소. 첫 로그인 때 채워집니다 |
| `kloudhub.allowSelfSignedCertificate` | `false` | HTTPS 자체서명 인증서를 허용합니다. 신뢰하는 내부망에서만 켜세요 |
| `kloudhub.ssh.identityFile` | (빈 값) | 접속에 쓸 개인키 경로(예: `~/.ssh/id_ed25519`) |
| `kloudhub.ssh.defaultUser` | (빈 값) | 로그인 계정을 알 수 없을 때 쓸 사용자 이름 |
| `kloudhub.ssh.allowPrivateAddress` | `false` | 공인 IP가 없는 서버를 사설 IP로 직접 접속합니다(VPN 등) |
| `kloudhub.ssh.configFile` | (빈 값) | 접속 정보를 기록할 SSH config 파일. 비우면 `~/.ssh/config` |
| `kloudhub.ssh.openPath` | (빈 값) | 접속한 뒤 열 원격 폴더(예: `/home/ubuntu/project`) |
| `kloudhub.refreshIntervalSeconds` | `0` | 목록 자동 새로고침 주기(초). 0이면 끕니다 |

## 로그아웃

제목줄 `···` → **로그아웃**을 누르면 이 PC에서 토큰을 지웁니다. 토큰 자체를 폐기하려면 웹의 **설정 → API 토큰**에서 지우세요.
